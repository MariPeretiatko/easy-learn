# Easy Learn

Локальное приложение для изучения языков и общих тем. React, строгий TypeScript, Vite, Dexie/IndexedDB и Zustand. Светлая тема по умолчанию, шрифт Comfortaa, адаптация для телефона.

## Запуск

Нужны Node.js 22+ и pnpm 10. Зависимости фиксируются в `pnpm-lock.yaml`.

```bash
npx pnpm@10.34.7 install --frozen-lockfile
npm run dev
```

Откройте http://127.0.0.1:5173. В Windows можно использовать `start-easy-learn.cmd`. Для доступа из локальной сети запустите `npm run dev -- --host 0.0.0.0`; для постоянного адреса, установки PWA и полноценной работы возможностей браузера нужен HTTPS.

## Возможности

- Библиотека: папки уровней, тематические модули, колоды и восстанавливаемые черновики. Подготовленный немецкий каталог импортируется один раз. Пользовательские языки и общие темы добавляются в верхнем списке или настройках.
- Редактор: автосохранение, импорт CSV/TSV, изображения с обеих сторон, форматирование, поиск и изменение порядка карточек.
- Карточки: переворот, озвучивание, свайпы, самооценка и интервальное повторение. Изменение общей карточки отражается во всех использующих её колодах; история повторений сохраняется.
- Заучивание: выбор одного или нескольких модулей/колод, новые и ошибочные слова требуют двух верных ответов подряд, знакомые — одного. Повтор появляется после трёх других заданий, если в очереди достаточно материала.
- Письменные ответы: явные допустимые варианты задаются по одному на строке. Запятые не разделяют варианты автоматически. Учёт регистра и требование немецких артиклей настраиваются перед занятием. Enter/«Готово» отправляет ответ; выход из поля не запускает проверку.
- Тест: количество заданий, направление, выбор ответа, письменный ввод, верно/неверно и подбор. Ответы можно изменить до финальной кнопки «Проверить тест». Результат и история ответов сохраняются одной транзакцией; завершённый результат можно открыть по ссылке.
- Игры: подбор пар и Blast. Старые ссылки на Blocks открывают подбор пар.
- Чтение: интерактивные слова и фразы, сохранение словарных карточек и позиции, настройка размера текста.
- Видео: YouTube, импорт субтитров, синхронный транскрипт, повтор фрагментов, A–B, скорость и диктант.
- Прогресс, поиск, недавние материалы, экспорт CSV и полные резервные копии JSON.

Существующие карточки переиспользуются по языкам, термину и переводу. Разные значения одного слова остаются отдельными записями. Удаление колоды сохраняет слова; удаление слова очищает его членство и историю.

## Проверки

```bash
npm run check                 # TypeScript, неиспользуемый код, модульные тесты, production-сборка
npm run test:e2e               # Chrome, dev-сервер поднимается автоматически
npm run test:e2e:production    # Проверки собранного приложения, включая настоящий офлайн-режим
```

Для браузерных проверок нужен Chrome; установить его для Playwright можно через `npx playwright install chrome`. Перед production-проверками выполните `npm run build`. Для собственного сервера задайте `E2E_BASE_URL`.

CI выполняет те же проверки и сохраняет трассировки при ошибке. Структура кода и правила изменений описаны в [DEVELOPMENT.md](DEVELOPMENT.md), аудит и результаты рефакторинга — в [docs/ARCHITECTURE_REVIEW.md](docs/ARCHITECTURE_REVIEW.md).

## Данные и ограничения

Библиотека хранится в браузере и не синхронизируется между устройствами. Вход, облачная база и профили с разграничением доступа пока не подключены. Локальный профиль — это имя и оформление, а не аккаунт.

Перед сменой устройства или очисткой браузера сохраните JSON через настройки. Восстановление заменяет текущую библиотеку после подтверждения; копии старого формата поддерживаются. Размер импортируемой копии ограничен 20 МБ. Изображение одной стороны карточки ограничено 3 МБ.

Перевод работает через небольшой локальный словарь с ручным дополнением. Субтитры загружаются пользователем; YouTube требует интернета. Незавершённое упражнение хранится в памяти, поэтому перезагрузка сбрасывает текущую попытку. Черновики редактора и завершённые тесты сохраняются.

## Импорт материалов

В редакторе можно вставить пары, разделённые табуляцией:

```text
Haus	дом
Baum	дерево
```

CSV поддерживает UTF-8/BOM, кавычки, многострочные значения и разделители `,`, `;`, tab:

```csv
word,translation,example,tags
Hund,собака,Der Hund spielt.,A1|животные
Katze,кошка,Die Katze schläft.,A1|животные
```

Для видео доступны SRT/VTT и JSON:

```json
[
  {
    "start": 0,
    "end": 3.5,
    "text": "Hallo Welt!",
    "translation": "Привет, мир!"
  }
]
```

Время задаётся в секундах. Переводы не генерируются автоматически.

Исходные каталоги и тематическая структура находятся в `src/data/`; они используются генераторами `scripts/prepare-library.mjs` и `scripts/organize-library.mjs`. Большой сгенерированный каталог хранится компактно и не форматируется Prettier. Исходные идентификаторы и данные миграции нужно сохранять.

## Публикация и снимки

```bash
npm run build
npm run preview
node scripts/screenshots.mjs
```

Содержимое `dist/` размещается в корне статического HTTPS-сайта с перенаправлением маршрутов приложения на `index.html`. Сборка включает офлайн-кэш страниц, шрифтов и подготовленного каталога; внешнее видео не кэшируется. Скрипт снимков работает в изолированном демонстрационном браузере и сохраняет изображения в `artifacts/preview/`. Для другого адреса задайте `PREVIEW_URL`.
